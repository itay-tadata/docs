## Agent

An **agent** is an AI worker you build in Tadata. It has a goal (defined by its instructions), the tools it needs to do its job (connectors), and a way to run (triggers or chat).

**Example:** A meeting prep agent that checks your calendar each morning, looks up each external attendee in your CRM, and emails you a briefing.

## Template

A **template** is a ready-made agent for a specific use case. It comes with instructions and connectors already configured — you just authenticate and run.

Templates are the fastest way to get started. Browse them in the [Templates](/templates/introduction) section.

## Connector

A **connector** is a pre-built integration with an external service — Slack, Gmail, GitHub, HubSpot, and 50+ more. When you add a connector to an agent, the agent can read and write to that service.

Connecting a service takes one click for most tools (OAuth handles the authentication automatically).

## Connection

A **connection** is one account signed in to a connector. A connector can hold several — a shared team inbox and each person's own inbox, for instance — and each one carries a name so your agent knows which to use for which job.

Every connection also has an access level: **Team** (everyone in your workspace), **Personal** (just you, anywhere) or **Private** (just you, in your direct messages). See [Connections & Access](/connectors/connections).

## Trigger

A **trigger** is what makes your agent run. There are two types:

- **Schedule** — the agent runs automatically at a set time (e.g. every Monday morning, every night at 2am)
- **Webhook** — an external system kicks off the agent when something happens

You can also start a conversation with any agent manually at any time.

## Conversation

A **conversation** is a chat session with your agent. You can use it to run the agent on demand, ask it to do something specific, or adjust its behavior. Conversations are saved so you can review what your agent did.

Direct messages and web chats are visible only to you. Conversations in a Slack channel are visible to your workspace, like any other channel thread.
