Tadata is an **AI agent builder**. Connect your tools, describe what you want an agent to do, and it runs — on a schedule, on demand, or triggered by events.

No code required.

<Card title="Get started in 5 minutes" icon="rocket" href="/getting-started/quickstart" horizontal>
  Build your first agent
</Card>

## How it works

<Steps>
  <Step title="Start from a template or a blank agent">
    Browse ready-made agents for common workflows, or describe what you want from scratch.
  </Step>
  <Step title="Connect your tools">
    Each agent connects to the services it needs — Slack, Gmail, GitHub, HubSpot, and 50+ more. One-click authentication, no setup required.
  </Step>
  <Step title="Set it running">
    Schedule your agent to run automatically, trigger it from a chat, or hook it up to an external event.
  </Step>
</Steps>
