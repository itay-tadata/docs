The fastest way to get started is with a template — a pre-built agent with instructions and connectors already set up.

<Info>
  **You'll need:** A Tadata account ([sign up here](https://app.tadata.com/signup))
</Info>

## Step 1: Pick a template

1. Log in to [Tadata](https://app.tadata.com)
2. Go to **Templates** in the sidebar
3. Browse the gallery and click on a template that fits your goal

Not sure which to pick? Try [Prep for Meetings](/templates/prep-for-meetings) — it's a good first agent that connects to tools most people already use.

## Step 2: Connect your accounts

Each template lists the services it needs. Click each connector to authenticate — most use one-click OAuth and take a few seconds.

You can skip authentication for now and come back to it later.

## Step 3: Review the instructions

The agent comes with a pre-written prompt explaining what it should do. Read through it and edit anything you want to customize — for example, changing which Slack channel to post to, or what kinds of roles to search for.

## Step 4: Run your agent

Click **Create Agent**. Most templates are set to run on a schedule automatically — you don't need to do anything else.

You can also start a conversation with your agent at any time to run it on demand or ask it to do something specific.

<Check>
  Your agent is live. It will run automatically on its schedule and you can chat with it whenever you want.
</Check>
