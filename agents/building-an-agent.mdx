If the templates don't cover your use case, you can build a custom agent by describing what you want in plain language.

## Create a new agent

1. Click **New Agent** in the sidebar
2. Describe your goal — for example: *"Monitor our Slack for customer complaints and create a Linear issue for each one"*
3. Tadata opens a live conversation with a builder that asks follow-up questions and researches what your agent will need
4. As the conversation unfolds, the builder configures the agent — its name, instructions, and connectors — then introduces itself when it's ready

You don't need to get the description perfect upfront. The builder will ask clarifying questions to get the details right.

## Editing your agent

Your agent's instructions, connectors, and settings can all be changed at any time. The easiest way is to just tell it what you want to change in a conversation:

- *"Also send a Slack notification when you create an issue"*
- *"Focus only on complaints about billing"*
- *"Remove the GitHub connector, I don't need it"*

The agent will update its own configuration based on your instructions.

You can also edit settings directly from the agent's **Build** tab.
