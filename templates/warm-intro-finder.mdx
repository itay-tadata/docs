Find the warmest path from your team to any target contact on LinkedIn. The agent checks for direct connections first, then finds second-degree paths through the target’s colleagues — surfacing mutual connection counts and shared experiences so your intro request lands with the right context.

## What it does

1. Accepts a list of target LinkedIn profile URLs
2. Checks if any team member is directly connected to each target
3. If no direct connection exists, finds colleagues at the target’s company who are connected to a team member
4. Compares profiles to identify shared experiences (same university, former employer, programs like YC)
5. Outputs a structured table with every intro path, network distance, mutual connection counts, and shared context

## Connectors

| Connector | What it's used for |
|---|---|
| LinkedIn Automation | Search connections and find mutual contacts |
| LinkedIn Profile Scraper | Fetch full profiles for shared experience analysis |
| Google Sheets | Store and share the warm intro results |

## How to run it

Run on demand — provide a list of target LinkedIn profile URLs and the agent finds the best intro paths across all authenticated team LinkedIn accounts.
