Connectors are pre-built integrations with external services. When you add a connector to an agent, the agent can read and write to that service — sending Slack messages, creating Linear issues, searching Gmail, and so on.

Tadata has 50+ connectors, with new ones added regularly.

## Connecting a service

Most connectors use OAuth — click **Connect**, authorize access, and you're done. Tadata handles authentication and keeps the connection active automatically.

Some connectors use an API key instead. These ask you to paste a key from the service's settings page.

### Services that run on your own address

A few services give every customer their own address — a Shopify store domain, for example, or a workspace subdomain. Those connectors ask for that detail on the setup page before you sign in, so the sign-in goes to your own account rather than a generic one.

- **Sign in** stays unavailable until the required details are filled in. If something is missing, the page tells you which value it needs.
- Your details are saved as soon as you sign in, so they're still there if you come back to finish setup later.
- Changing one of those details after signing in means signing in again — the new address needs its own authorization.
