Connectors are pre-built integrations with external services. When you add a connector to an agent, the agent can read and write to that service — sending Slack messages, creating Linear issues, searching Gmail, and so on.

Tadata has 50+ connectors, with new ones added regularly.

## Connecting a service

Most connectors use OAuth — click **Connect**, authorize access, and you're done. Tadata handles authentication and keeps the connection active automatically.

Some connectors use an API key instead. These ask you to paste a key from the service's settings page.

## Disconnecting an account

When you no longer want your agent using a connected account, just ask it — in chat or in Slack:

- *"Disconnect my Gmail"*
- *"Remove the second HubSpot account"*

The agent will confirm which account it's removing and take care of it. You can also remove an account yourself from the connector's page in the platform.

Agents can only remove accounts you're allowed to manage — an account someone else connected stays theirs, and only they can disconnect it.
